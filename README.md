# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 评审收尾规则

- **异常判定**：同一方案以各评委有效加权分的中位分为共识基准，偏离超过 15 分的评分自动挂起；挂起后剔除该分再算中位、迭代到稳定。挂起评分的原值与意见保留，但不计入名次，待评审复核。
- **评委更替**：退出评委未提交的草稿转交替补继续填写；已提交的评分原值保留并标记"待确认"，替补确认后才计入名次（也可自行评分替代）。退出评委身份只读。
- **作废重算**：判定不入库，评分一改动（保存/提交/退回/确认/更替）旧判定与名次立即作废、整体重算。
- **不硬凑名次**：有效评分不足 2 条的方案单列在榜单之后，不给名次；并列采用标准竞赛排名（1,1,3）。
- **多窗口并发**：评分带 `rev` 版本号，保存时做乐观并发检测；后保存者会看到"已被另一窗口更新"，其草稿保留在表单中不覆盖对方，可选择读取对方最新版或显式强制覆盖。
- **失败回滚**：保存（写入 localStorage）失败时事务化回滚到上一版，恢复名次与未完成项。
- **旧数据兼容**：缺少 `version/roster/rev/verdict/confirmStatus` 的旧数据按默认值补全后打开，并写入兼容审计事件。
